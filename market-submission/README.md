# dshmarket submission

dshmarket reads the [awesome-dsh-plugin registry](https://github.com/awesome-dsh-plugin/awesome-dsh-plugin). Submit `danielyongzx1__dsh-clanker-bridge.yml` as the single new file `data/plugins/danielyongzx1__dsh-clanker-bridge.yml` in a PR to that repository. Do not edit its generated README files.

Their contribution rules require a public working repository with `dsh.bundle`, an installable package, and the `dsh-plugin` topic. **The repository must be at least one day old when submitted.** Wait for that eligibility before opening the listing PR; publication does not mean the plugin is already listed or approved.

Suggested PR title: `Add dsh-clanker-bridge to Remote & Mobile`

Suggested PR body:

```text
Adds dsh-clanker-bridge under Remote & Mobile.

The MIT-licensed plugin connects Clanker mobile clients to official Harness Desktop through an authenticated remote-agent bridge. It includes streaming, effort/usage, approvals/questions, cancellation and original-byte file transfer. Pairing credentials are generated per device; no private configuration or Clanker checkout is shipped.

Installable from GitHub without build scripts, with a prebuilt release archive. Tested on Windows with Harness Desktop 0.2.1-rc.5. Protocol/file tests use local fixtures without provider calls.

Only the new data/plugins entry is included; generated READMEs are unchanged.
```
